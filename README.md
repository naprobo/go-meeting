This is a meeting report system designed for multi-person meetings. 

Each participant uses the system to submit their own report content. 

During the meeting, the facilitator uses the system to display each participant's report. 

After the meeting, the recorder submits a summary of the meeting through the system.

The delivery management function, as part of the meeting, is also managed through this system, 
allowing users to view the delivery status of each project during the meeting.
